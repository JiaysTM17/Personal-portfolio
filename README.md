## 🚀 Khởi Chạy Local

Mở terminal tại thư mục dự án và chạy:
```bash
# Sử dụng Python:
python -m http.server 3000

# Hoặc sử dụng Node.js:
npx serve -l 3000
```
Sau đó mở trình duyệt tại: `http://localhost:3000`
