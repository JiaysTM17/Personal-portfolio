## 💻 Chạy Dự Án Local

Mở terminal tại thư mục dự án và khởi chạy bằng Python hoặc Node.js:

```bash
# Cách 1: Python HTTP Server
python -m http.server 3000

# Cách 2: Node.js Serve
npx serve -l 3000
```

Sau đó truy cập tại trình duyệt: `http://localhost:3000`
